# JasonCBuilds Applied Analytics

A practical, project-based learning portfolio in **SQL, Power BI, and Python** focused on supply chain engineering, logistics optimization, and the FuelzUs mobile vehicle-services marketplace.

> **Status:** Learning program initialized. Example jobs and financial figures are fictional, not real business performance.

## Wednesday Build Lab
- **When:** Wednesdays, 8:00–10:00 PM Eastern (America/New_York)
- **Start:** November 11, 2026
- **Approach:** Brief preparation before class; hands-on building, testing, and documentation during class
- **Starting skill levels:** SQL new, Power BI new, Python basic

Only claim results after testing them. Use synthetic, self-owned, or appropriately licensed public datasets. Do not upload confidential employer/customer information. Link finished work to the [JasonCBuilds portfolio repository](https://github.com/JasonCBuilds/Portfolio-Website) once it is ready for presentation.
